# Technology imagery

Each of the ten platforms takes two assets. **Drop files in, nothing else.**

```
/public/tech/grip-rubber.jpg             macro detail photograph
/public/tech/grip-rubber-schematic.svg   line diagram of the mechanism
```

The macro shot sells the material. The schematic sells the engineering. They
do different jobs, so both slots exist and either can be filled on its own.

| Asset | Filename | Spec |
|---|---|---|
| Macro | `<tech-id>.jpg` | square, ≥1200px, tight enough to read texture |
| Schematic | `<tech-id>-schematic.svg` | 16:9, line art, transparent, strokes in `currentColor` if possible |

Once a macro exists for a platform, it replaces the exploded 3D view in that
platform's readout.

**What each macro should actually show**

| Tech id | Shoot this |
|---|---|
| `ground-last` | the last itself, foot-scan data overlaid |
| `grip-rubber` | rubber surface at grain level, both tunings side by side |
| `two-ground-sole` | the two grip zones meeting on one outsole |
| `dry-system` | the drain port mid-pump, and the zip-in liner |
| `fold-heel` | the heel caught mid-fold |
| `second-skin` | a worn sole with the second pattern surfacing |
| `resole` | the sole separated from the upper |
| `foot-sensor` | the sensor in the midsole cavity |
| `fresh-lining` | the treated footbed, macro |
| `heat-stable-foam` | foam cell structure |
