# Product art

The 11 `.png` files in this folder are **1×1 pixel placeholders**. Replace any
of them with a real image, then flip that shoe id to `true` in
`lib/assets.ts` → `HAS_ART`.

| Setting | Value |
|---|---|
| Format | PNG with alpha |
| Size | square, 1200×1200 or larger |
| Background | transparent |
| Framing | shoe centred, ~8% padding |
| Angle | keep one consistent angle across all eleven |

Until a flag is flipped, each shoe shows a labelled placeholder panel in the
layout and the procedural 3D form in the scene.

Shoe ids: `alleys`, `traktor`, `doorway`, `nightshift`, `beta`, `session`,
`reverse`, `train`, `recover`, `everyday-mid`, `1973`
